# Forma – Online Clothing Store

Forma is a full-stack e-commerce web application for selling
men's, women's, and kids' clothing and accessories.

## Features

- User registration and login
- Product browsing and search
- Category, size, color and price filtering
- Product variants
- Shopping cart
- Wishlist
- Checkout and online payment
- Order tracking
- Product reviews
- Admin dashboard
- Inventory management
- Coupons and discounts

## Technology Stack

Frontend:
- React / Next.js

Backend:
- Node.js / Next.js API Routes

Database:
- PostgreSQL
- MongoDB

Version Control:
- Git and GitHub
